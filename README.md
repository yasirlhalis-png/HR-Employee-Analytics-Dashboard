# HR Employee Analytics Dashboard

## Project Overview

The HR Employee Analytics Dashboard is a data analytics project developed to analyze employee information and provide clear insights into the company's workforce.

The project covers data cleaning, Pivot Table analysis, charts, slicers, KPI cards, and an interactive HR dashboard.

## Project Objective

The main objective of this project is to analyze HR employee data and understand important workforce patterns such as employee distribution, overtime, departments, business travel, job satisfaction, salary, age, education, job roles, and attrition.

## Data Cleaning

Before analysis, a separate copy of the original dataset was created for data cleaning.

The following data-cleaning activities were performed:

- Checked for duplicate values
- Removed repeated records where required
- Checked and handled blank or missing values
- Used sorting and filtering to inspect the data
- Checked the dataset for consistency
- Compared the original data with the cleaned data

This helped prepare the dataset for accurate analysis.

## Key Insights

The analysis provides several important insights:

- The company has a total of 1,480 employees.
- Male employees are higher in number than female employees.
- Research & Development has the largest number of employees.
- 418 employees work overtime.
- 238 employees have left the company according to the Attrition field.
- Job Satisfaction levels 3 and 4 have the highest number of employees.
- The 26–35 age group has the largest number of employees.
- Life Sciences is the largest education field.
- Sales Executive is the largest job role by employee count.
